# 中国市场工作流：可运行演示

从仓库根目录运行：

```bash
bash scripts/run_cn_demo.sh
```

入口使用 Python 3.11 和 uv 安装依赖、检查 LightGBM 环境、生成合成日线、编译独立配置，完成训练、回测和质量检查。配置权威入口为 [configs/cn/profile.json](../../../configs/cn/profile.json)，详细语义见 [配置说明](../../../configs/cn/README.md)。同目录原 workflow_config_cn_demo.yaml 仅保留为旧演示参考，新入口不直接运行它。

新数据保存在 `.data/cn_current_demo/<配置指纹>/`，每次运行配置、逐笔费用和质量结果保存在 `.data/cn_runs/<时间戳>-<指纹>/`。MLflow 使用 `.data/qlib_mlruns_mlflow3_12.db`，旧数据与结果保留。

当前以现行制度回放历史日期的合成数据，不是历史制度复原。双向佣金万二；默认佣金最低5元、含规费且不含过户费仍为账户假设。佣金、过户费、卖出印花税和滑点成本分别计算。执行器处理板块数量约束、T+1、现金、日成交量参与率与涨跌停限制；日期使用交易所日历，标签边界移除未来数据跨区间样本。

2026-09-26 一键入口实测：123 个有效 IC 日、122 个交易日，质量门槛通过。全部行情与基准均为虚构数据，不能用于评价真实策略收益。当前入口拒绝直接切换为真实数据；PIT、公司行动、行业约束、异常状态和实盘仍需独立实现及验收。
