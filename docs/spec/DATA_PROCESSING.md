# 免费日频数据处理标准与执行规程

状态：生效，版本1，2026-09-28；用户明确要求先登记标准/步骤再处理。实施基线85c4da73。范围：既有FINV 2026-09-24行情及BaoStock缓存，中证500历史成员，2015-01-05至2026-09-24日频；不重新联网采集，不覆盖原始数据。关联DATA01—06、FD01—07、SR05/06。本文负责物理处理合同，来源选择归DATA_SOURCES，统计定义归FACTOR_ANALYSIS，阶段状态归IMPLEMENTATION。

## 1. 数据分层与定位

1. 原始凭据：保全压缩归档/发布清单、旧解包目录、原BaoStock CSV、旧registry与研究结果。先核对SHA，不能以新处理结果回填历史来源。
2. 冻结输入：独立新目录`processed/free_cn_20260924_v2/`复制已核对文件；日历、历史成分、基准SH000905、全部涉及的行情字段和缓存逐文件列SHA-256及字节数。不能用硬链接让旧文件改写传播到新副本。源文件来自哪个归档成员须有比对证据；缓存只能标本次观察/核验，旧采集是否完整结束仍为unknown。
3. 规范面板：按历史成员展开，日历×当日在册证券唯一；价格/量/额单位与缺失规则固定。按年度写CSV分块及manifest，文件有内容摘要、行数/唯一键、日期范围、缺失计数、输入身份、物化版本及来源；不以CSV单文件替代长期所有格式选择。
4. 研究派生：消费冻结输入；结果写新文件，披露样本、缺口、排除及未认证性质。既有真实训练/实盘能力缺口不因本批数据处理关闭。

新IO实现归`adapters/snapshot_files.py`及`adapters/data_preparation.py`，目录适配器接入读取；纯时间/价格判定归domain，既有data_directory/free_sources/factor_pipeline只作为迁移调用面，不新增无归属顶层文件。脚本解析参数/调用处理入口，不复制另一套标签或统计公式。

## 2. 输入与字段标准

- 日期使用快照交易日，不用自然日或删缺口后的行号。证券身份本批仍沿用供应商代码+记录的区间，不宣称已验证所有历史代码复用；成员区间端点按供应商文件闭区间解释，重叠先归并为同日唯一成员。数量偏离500如实报告，不机械截断。
- FINV `price_basis=finv_adjusted_v1`：close/open/high/low/vwap已经复权归一化；原价=字段/factor；标签直接close比值。volume为反向复权手数，原始股数=volume×factor×100；amount千元→元乘1000。factor须正且有限；不得再次复权。原始价格式须另声明`raw_with_factor_v1`，未知不猜测。
- `turn`是百分数值，0.1586表示0.1586%；流通股本=原始股数/(turn/100)，流通市值=原价×流通股本。近似派生，非官方股本。turn为空保持缺失；0是已观测零换手，均值可保留，不能反推股本。
- 不填0、不前向填充行情或状态。NaN表示缺失；区分源NaN、字段覆盖外、缓存缺日期、非成员与标签未成熟。重复缓存日期、逆序、非法日期/状态/非有限数拒绝；不得last-wins。
- bin header须非负有限整数；每字段独立映射到日历，越界/长度不合法拒绝。必需字段缺文件拒绝，观测NaN可保留并计数；不静默按最短长度截断。OHLC正值/高低包络与volume非负检查覆盖全部处理标的，不仅期末池；相对浮点容差显式为1e-5。
- 质量错误先停止发布并保存报告；不自动丢弃问题证券/异常bar以求通过。实际缺失可发布为有披露的受限输入，但不能宣称完整PIT/可成交数据。日历、成分、证券状态的历史available_at未知保持unknown。

## 3. 快照格式2与消费保护

旧schema_version=1登记保持可浏览与原文件不变；其清单摘要不构成可复现分析许可。新版本不原地升级旧身份。

v2在原记录基础上新增：`interpretation`（价格/单位/成员集合/缓存来源限制）、每组件`files`（相对该组件URI的`path`、`sha256`、`size_bytes`），以及`quality`报告。URI、file path必须是根内相对路径，不允许越界/符号链接。文件型组件用path为`.`；目录型组件路径唯一且排序。指定csi500及all成分都进入文件清单。

`content_digest`采用规范JSON（UTF-8、sort_keys、紧凑分隔符）的SHA-256，覆盖除content_digest/created_at以外所有记录字段；组件摘要为files数组的同算法摘要。解释版本、具体成分、覆盖、available_at、质量和来源变化均改变身份。只有schema2、published、摘要完整一致且必需质量门禁通过才可用于研究/物化。

读取器在每次读取实际字节时核对长度与SHA，随后直接解析这份已核验的bytes；禁止校验路径后重新打开路径解析。仅允许缓存从同一内容身份得到的不可变解析对象，不缓存“这个路径曾验证过”的布尔值。未知/缺组件/内容漂移/未发布按DATA04-A错误码拒绝；浏览旧元信息标limited，不能只靠provenance.complete标reproducible。

发布先校验再以原子文件创建提交registry（并发相同ID异内容不覆盖）；暂存失败不产生published。新目录即使有人改文件，下一次实际读取也必须因摘要不符拒绝；不能把只读权限当身份验证。无需迁移SQLite。

## 4. 标准处理步骤及失败出口

| 步骤 | 操作 | 验收/失败处理 |
| --- | --- | --- |
| DP1 冻结规范 | 本文、来源/架构索引、处理任务与限制登记 | 先提交规范检查点，尚不声明实现 |
| DP2 检查/冻结原料 | 验原始archive SHA；逐成员核对选择的解包文件；复制全历史成员/基准所需行情及1791缓存、计算内容清单 | 差异拒绝，保留旧原料；单独记录11个无缓存成员是否在研究区间内 |
| DP3 质量/候选 | 日历/成员、bin、OHLC、缓存结构及逐日成员内覆盖；来源未知字段披露；验证后只在内存构造候选身份 | 任一结构/非法值/必需组件失败不发布；真实缺测逐类计数，不冒充已核实停牌原因 |
| DP4 物化/发布 | 每年度、每证券的合法成员日期，输出规范字段；唯一标的排序后limit；字节级复跑与独立键集合/字段换算校对，全部通过后才原子登记 | 重复键/错位/内容身份改变拒绝且不登记；新版本分块，不覆盖旧360行样例 |
| DP5 研究重算 | 三条入口统一读取已验证快照，历史池与标签掩码，NW缺口/跨折标签修复；复跑2025-01-02至2026-09-24试点 | 缺证据的统计项unavailable，不能为了产生p值删缺IC；结果保持探索性 |
| DP6 交付 | 相关反例/回归、完整门禁、真实数据脱敏摘要；回写spec/commit/push | 分别报告数据处理、研究复算及尚未验收能力 |

断点恢复只复用摘要匹配的冻结文件；任何当前文件差异不自动覆盖。输出目标存在但身份不同即拒绝，用户旧数据不清理。本批只使用已有缓存，不探测黑名单解封，不改变网络访问策略。

## 5. 面板、标签和研究选择

规范面板列：date、symbol、adjusted_close、raw_close、raw_volume_shares、amount_cny、turn_percent、tradestatus、is_st、float_shares_estimate、float_cap_estimate。未知写空字符串；清单记录缺失计数。输出为观察日数据，**不预先用未来状态删除当前因子行**；未来窗口条件仅决定标签可用性。

因子计算可读取加入前历史作为回看，但排名/暴露拟合/IC以t日成员为准。标签h为完整交易日步数；首尾及内部任一日缺价格/状态、停牌或ST则该标签不可用。为避免伪造板块/年代涨跌停规则，本次明确采用保守样本规则：排除high≈low的单价日，不再把统一9.8%/4.8%称涨跌停判定；这是研究样本近似，会排除部分正常单价日，不是成交能力证明。窗口跨出指数不自动视为不能持有；缺到期价格仍拒绝标签。

NW必须复用FACTOR_ANALYSIS §4.1的实现及完整日期轴；预先声明因子回看/暴露窗口造成的热身区间可排除，末尾h日未成熟可排除，不能根据IC是否为空反向剪样本。中间缺IC使显著性与对应FDR筛选unavailable，描述均值仅针对有效观测并披露计数。

每折训练统计截止于train.stop-1；t+h>=train.stop的训练标签剔除。测试块评价同样披露块末未成熟标签，不从下一块借结局；同一训练截止点，修改此后的价格不能改变已选因子。成本筛选仍只是近似，不等于回测；实际分折模型训练/TrialLedger不在本批伪造。

## 6. 兼容与能力边界

- 缓存修复：新采集必须检查游标终态/内容/请求范围，原缓存无完成记录时不得直接当成功续传；可离线结构/覆盖审计并登记`historical_completion=unknown`，本次研究以实际可用行且披露未知为限。新增来源数据另开版本目录。
- 旧通用因子结果不改写。来源格式有明确口径才计算；schema2可经目录端口读取已验证字节，旧演示路径仅按明确的已登记模拟格式兼容，不能借默认路径把免费快照当原始价。旧未知口径拒绝并说明。
- schema2数据处理通过只证明固定输入/口径及限定质量范围；不是供应商历史修订/PIT认证，不关闭完整训练、交易、云部署或SR01—04执行/验证任务。FD状态逐项由证据更新，不能因新目录存在就宣称完成。

## 8. 已交付入口与重跑操作

实际根目录由`--data-root`传入（本机使用`~/.qlib/qlib_data`），不要硬编码到应用核心。推荐snapshot_id为`free_cn_20260924_processed_v1`，登记文件`_registry/<snapshot_id>.json`；冻结输入`processed/<snapshot_id>/`，规范面板`processed/<snapshot_id>/panels_v2_1/`，年度CSV及manifest都在其下。manifest覆盖输出哈希、每年行数/唯一键、输入身份、缺失类别和验证项。目录存在不等于发布，消费者必须通过registry解析及VerifiedFiles核验。

```bash
# 离线重跑：完全相同的冻结文件/面板可复用；任何差异拒绝覆盖。
extensions/workbench/.venv/bin/python scripts/prepare_free_data.py --data-root ~/.qlib/qlib_data
# 新版本研究输出文件必须不存在；不要覆盖证据目录中的已交付报告。
extensions/workbench/.venv/bin/python scripts/run_factor_research.py \
  --data-root ~/.qlib/qlib_data --registry ~/.qlib/qlib_data/_registry \
  --snapshot-id free_cn_20260924_processed_v1 --output /tmp/my-new-research.json
# slice/walkforward入口使用相同根、registry、snapshot-id和独立output参数。
# 独立原文件逐值校验；仅读文件，不接触数据源网络。
extensions/workbench/.venv/bin/python docs/spec/evidence/20260928-verify-processed-panel.py \
  --data-root ~/.qlib/qlib_data --snapshot-id free_cn_20260924_processed_v1
```

如本批来源发生修订，先登记新输入范围/解释版本，再使用新的snapshot_id处理；此CLI仅处理既有固定来源，不是通用自动更新器。没有采集完成凭据的旧缓存不能用fetch脚本“跳过即成功”；新采集另用版本目录，保持既有顺序/限速规则。该缓存保护已离线测试，本批没有联网验证供应商恢复。

本批验收、缺口数量、研究复算及仍未支持能力见[IMPLEMENTATION顶部](IMPLEMENTATION.md)和[处理证据](evidence/20260928-data-processing.json)。数据固定与语义正确不等于供应商历史真值、PIT或可执行交易认证。工作台通用因子UI仍使用原CN配置；本批未自动替换演示数据或伪称真实训练/回测已接入。
