# 研究工作台使用闭环（2026-09-26）

用户补充 U09：每次 RD-Agent 研究要有结果和可点击的过程；整体可用、易用、可观测、可比较、可辅助决策。

## 生效合同

- RW01：研究列表展示日期、可读名称、结果状态、因子数、主要指标；可搜索、分页，缺产物不伪装成功。
- RW02：点击研究可查看假设、因子说明/公式、生成代码、阶段时间线、执行日志、反馈和质量。历史记录仅按现存证据恢复，不通过最新成功标记覆盖其他会话。
- RW03：脱离 RD-Agent 运行时的 JSON 观察快照；可信本机 pickle 仅由显式 CLI 导出进程解析。HTTP不反序列化pickle；观察/读取接口不启动研究，启动仅由EXECUTION规定的写命令入口进行；跳过配置/凭据/LLM原始提示日志，内容脱敏、长度限制、路径限制。
- RW04：有回测报告的研究导入平台统一结果，使用同一回测/训练/比较界面。结果 revision 不可变；列表区分观察时间与原运行时间。
- RW05：决策摘要由应用服务计算，列出观测事实、质量/来源缺口、下一步；不以 Agent 接受意见或单次模拟收益推荐实盘。比较明确日期、初始权益、数据版本、成本情景差异；未知信息禁止排名。
- RW06：无结果会话仍能打开过程；不能以目录更新时间推断运行中或失败。局部失败/日志错误与整个研究终态区分。

## 全局方向与后续门槛

所有引擎围绕“找研究→理解结果→追溯过程→核对差异→决定下一步”组织，而不是只列技术ID。该链路是结果消费入口；U23补充的实验创建、模型复用、策略版本与前瞻模拟合同见 [RESEARCH_LIFECYCLE.md](RESEARCH_LIFECYCLE.md)，两者共同构成完整研究工作流，新能力尚未实现。执行/取消/持久化Attempt、真实数据/实时、遥测、布局保存仍按主spec独立验收；不以页面链接代替能力实现。

验收：历史成功及不完整记录可打开；主要指标与源报告相符；有日志可展开；凭据不出现在快照/API；CLI与HTTP一致；比较不能因未知版本产生排名；浏览器实际核对列表、详情、过程、比较及小屏。

## 历史实现证据（修复前快照）

- 离线导出27个历史会话；5个有回测报告，发布到同一平台结果库。最新研究5因子/19指标/13个可展开事件，保留原始反馈。无结果记录显示过程不完整，原进程状态仍为unknown。
- CLI `research-list` / `research-detail` / `review` 与 HTTP 共用服务。更新后的探针在退出时同步历史快照；其他RD-Agent入口通过显式导出命令同步。
- 对比额外检查窗口、首点权益、执行情景；锁定返回的revision。数据内容版本未知时不允许排名。
- API遥测为单进程最近300秒、最多10000请求；分开5xx与4xx，展示启动覆盖与容量截断；不宣称持久化遥测或任务失败率。
- 未修改RD-Agent tracked源码；Qlib核心未加入研究/UI依赖。真实实时数据、执行器与完整数据目录仍未实现。

最终验收：21项测试运行，20通过，1项Qlib环境隔离跳过（此前已在根环境验证）。浏览器实际完成列表→研究详情→因子展开→假设阶段展开→加入比较→系统观测；比较页截图排版正常。27份快照检查未发现已配置凭据。小屏专项布局验收仍保留在M2完整验收项。
