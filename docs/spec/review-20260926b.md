### 值得保留的做法（明确认可）

- **fail-closed 已成习惯**：样本不足、方向未登记、数据版本未知、配置完全相同都会显式返回不可用或退化，而不是编造数字。
- **schema 迁移显式且只增不改**：v1→v4 每一步都有测试与备份说明。
- **契约先改、代码后改**：本轮多次先动 spec（U18/U19/U20/U21/U22、UI06/UI07、VALIDATION/FACTOR_ANALYSIS），实现与验收跟随。
- **DTO 脱敏与来源标记一致**：路径、密钥、日志尾部在 API 边界统一处理；比较页把"最优/最劣"与状态色分开。
