## 历史核对结论（修复前快照）

对8条已发布运行逐项核对。其中7条来自引擎产物，直接对照6288个权益、成本、换手、收益和标量指标值，未发现数值不一致。行情均为本机构造模拟数据，因此“引擎原始记录”不等于“真实市场”。训练历史并未在本次逐值审计中完整验证；单点loss不能称完整学习曲线。对照脚本为 `scripts/audit_workbench_sources.py`，本机明细 `.data/workbench-source-audit.json`；脱敏保全副本见 [来源核对摘要](evidence/20260926-source-audit.json)，后续更新不得覆盖此历史证据。

| 信息 | 来源及标记 | 当前限制 |
|---|---|---|
| 通用引擎结果示例中的净值、loss、错误数、成功状态 | **手写演示样本**，generic-result.json | 非任何真实引擎的执行结果，不支持研究排名 |
| 权益、成本、换手、收益、IC | **引擎原始记录**，Qlib报告/MLflow或RD-Agent实验结果 | 模拟行情；费用执行可由定制CN适配器产生，非券商账单 |
| 区间权益变化、观测权益回撤 | **工作台计算** | 从报告首点开始；不是完整账户回撤，也不是Qlib原生超额回撤；旧definition_id含initial_equity的命名不准确，保留历史revision并通过来源说明纠正，新导入用observed_equity |
| 有效IC天数、常数预测天数、交易天数、passed_checks | **定制检查**，自建CNQualityRecord | 非上游原生验收；不证明alpha有效 |
| 费用、T+1、板块数量等情景 | **定制能力/研究假设** | 见CN配置；最低5元、滑点、参与率是账户或研究假设 |
| 因子假设、代码、解释、采纳意见 | **Agent生成内容/意见** | 保存于原日志不代表其解释正确或因子通过独立验证 |
| 结论、缺口、下一步 | **工作台规则提示** | 固定规则模板，不是引擎输出，也未额外调用模型做分析 |
| 恢复因子数、会话名称、时间线标题 | **工作台整理** | 只统计可恢复产物；未恢复不等于零因子；离线摘录非实时进度 |
| API错误率与P95 | **工作台实测 / 能力受限** | 仅当前HTTP进程；非引擎/任务错误率；300秒窗口，重启重置 |
| 严格排名、完整训练曲线、实时研究过程 | **能力受限** | 数据版本缺失、单点loss、离线快照均不支持更强结论 |
| 实时行情、实盘、任务失败率、界面启动停止、真实PIT/公司行动/行业风控 | **未接入** | 不以占位或配置项宣称实现 |

## 展示与契约

来源类型与行情性质分别标记。接口每条序列返回provenance（kind/label/source/limitations），revision返回逐字段清单；默认未知来源，不凭native前缀或数值存在判定原生。fixture优先于任何指标名称。此注解为查询时投影，不覆盖不可变历史结果；CLI与API共用分类器。

界面：全局图例、运行列表手写样本标记、回测/训练/研究详情字段来源表、派生指标及质量/规则提示标签；总览和系统展示能力边界表。未记录不填零，未恢复因子数不表示实际为零。比较包含手写样本时禁止排名。

## 审计隔离与修复记录

初次审计误用RD-Agent环境MLflow3.16访问3.12实验库，触发自动迁移。已保存完整迁移后备份，在副本上使用官方降级迁移恢复3.12，逐表比较所有保留列和记录一致、删除的迁移新增表均为空，再恢复原实验库；3.12读取及回归测试通过。审计脚本已改为SQLite只读打开源库、backup至临时副本，MLflow仅访问副本。没有迁移工作台业务库，也没有覆盖历史结果revision。
