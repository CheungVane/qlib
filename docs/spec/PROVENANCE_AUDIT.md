# 来源分类与能力声明合同

状态：生效；U10 / GOV-SOURCE / GOV-CLAIMS。2026-09-30将历史审计与持续规则分离；本文件不维护第二份实时能力表，当前实现与缺口见[IMPLEMENTATION](IMPLEMENTATION.md)。

## 1. 来源类型与展示规则

来源类型与行情性质分别标记。接口每条序列返回provenance（kind/label/source/limitations），revision返回逐字段清单；默认未知来源，不凭native前缀或数值存在判定原生。fixture优先于任何指标名称。此注解为查询时投影，不覆盖不可变历史结果；CLI与API共用分类器。

界面：全局图例、运行列表手写样本标记、回测/训练/研究详情字段来源表、派生指标及质量/规则提示标签；总览和系统展示能力边界表。未记录不填零，未恢复因子数不表示实际为零。比较包含手写样本时禁止排名。离线摘录不冒充实时过程，单点loss不冒充完整学习曲线；仅HTTP进程遥测不冒充引擎/任务错误率，必须披露窗口和重启覆盖。

下表约束分类，不表示对应能力已实现；历史样例审计的数字和覆盖范围仅见归档。

| 信息 | 来源及标记 | 语义限制 |
|---|---|---|
| 通用引擎结果示例中的净值、loss、错误数、成功状态 | **手写演示样本**，generic-result.json | 非任何真实引擎的执行结果，不支持研究排名 |
| 权益、成本、换手、收益、IC | **引擎原始记录**，Qlib报告/MLflow或RD-Agent实验结果 | 行情性质另按确切输入标记；引擎原始记录不等于真实市场。费用执行可由定制CN适配器产生，非券商账单 |
| 区间权益变化、观测权益回撤 | **工作台计算** | 从报告首点开始；不是完整账户回撤，也不是Qlib原生超额回撤；旧definition_id含initial_equity的命名不准确，保留历史revision并通过来源说明纠正，新导入用observed_equity |
| 有效IC天数、常数预测天数、交易天数、passed_checks | **定制检查**，自建CNQualityRecord | 非上游原生验收；不证明alpha有效 |
| 费用、T+1、板块数量等情景 | **定制能力/研究假设** | 见CN配置；最低5元、滑点、参与率是账户或研究假设 |
| 因子假设、代码、解释、采纳意见 | **Agent生成内容/意见** | 保存于原日志不代表其解释正确或因子通过独立验证 |
| 结论、缺口、下一步 | **工作台规则提示** | 固定规则模板不是引擎输出或Agent分析；若由Agent生成必须另标其来源 |

## 2. 免费来源

因子研究的候选免费来源与实测证据登记在[数据源清单](DATA_SOURCES.md)。新增类别 `free_community_unverified`，适用于FINV/BAO/EM/YF这类免费但非官方认证的来源：

- 每条数据、每个快照、每个派生指标必须能回答来源ID、上游（Tushare/AkShare/BaoStock/…）、获取时间、快照内容摘要与许可状态；未知即未知。
- 展示与报告必须直白标注“免费来源，未认证”，不得写“官方”“PIT完整”“可直接排名”。
- 免费来源不得替代A37真实研究验收，也不得用于实盘或盈利结论；缺失不得用默认值补齐。

## 3. 数据与人参与研究的新增产物

质量“可信程度”按DATA_PIPELINE ING06给来源证据、检查、跨源覆盖及历史时点四轴，禁止把完整率/同源重复校验/Agent自信度转成正确概率。人的方向/假设/公式标user_authored；Agent评议和建议标agent_generated；平台编译检查标platform_check；公式计算与统计标platform_computed，原始行情来源另外保留。以上为新增产物的provenance.origin字段枚举，不替换现有结果provenance.kind分类器。ready_to_test、可计算、统计可用和已验证策略分别表达；实际来源/能力声明须逐入口验收，当前基线不具备U29/U30完整流程。

## 4. 审计隔离与历史证据

核对历史实验库时使用只读源库和隔离副本，MLflow只访问副本；不得由审计触发原库迁移。字段来源注解是查询投影，不覆盖不可变结果revision。历史导出、脱敏与版本限制仍依[RD-Agent接入](RDAGENT_INTEGRATION.md)及[结果合同](RESULT_CONTRACT.md)。
