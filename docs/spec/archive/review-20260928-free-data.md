# 免费数据处理专项审查（2026-09-28）

代码基线：`2d1e2985`。审查对象：FINV快照`free_cn_20260924`、BaoStock enrichment缓存、登记/质量检查/物化、三条因子研究脚本及通用因子价格入口。用户要求核对处理是否正确。本批只读生产数据、在临时目录构造反例并更新spec/脱敏证据；未修业务代码、未重下数据、未重算历史研究结论。

**结论：原始归档与基础读取有可用证据，但从数据到可研究面板/标签的处理链未通过正确性验收。历史“物化可复跑”和“样本外评价”不能当作数据正确或无泄漏证明。**

证据：[机器摘要](../evidence/20260928-free-data-review.json)；[现有数据扫描](../evidence/20260928-free-data-scan.py)；[隔离反例](../evidence/20260928-free-data-probes.py)。两脚本使用workbench Python环境、显式`--output <临时输出文件>`，前者默认读取本机`~/.qlib/qlib_data`，后者只使用临时夹具；输出是缺陷观察，退出0不表示功能验收通过。原始归档、缓存、物化样例和旧证据均保留。

## 已核对成立的部分与范围

- 原始566MB归档SHA-256仍匹配下载清单；这只证明归档字节，不证明解包目录或补充缓存未变。
- 日历共6479日，2000-01-04至2026-09-24，严格递增且不重复；未据此认证所有历史交易日与交易所规则一致。
- 历史中证500的1802个标的，10个bin字段均存在，各标的内字段的起始索引/长度一致。本轮未发现错位，但现有门禁不能拒绝错位反例。
- 期末500标的通过现有OHLC/成交量检查；统计257975个缺失**字段观测**，不是257975个缺失交易日。原检查不验证每个历史成分/基准/停牌原因，因此不能外推全数据质量通过。
- BaoStock缓存1791文件、4601971行：本轮逐行结构扫描未见重复/非递增日期、非法状态枚举或非法换手率；128151行换手率为空，19行为0。此项未核对逐日预期覆盖与外部真实行情，也不证明采集无截断。
- 原始价格恢复、成交量反向复权及百分比换手率反推股本的辅助函数方向正确。SH600000在2026-09-24恢复收盘约9.00、成交量528363.96手、成交额475964875元，与之前登记的单点来源核对一致；不是本轮重新在线报价核对。
- 65项现有相关测试通过：free_sources 19、data_directory 20、factor_pipeline 23、fetch_pacing 3。以下反例仍成立，说明原测试覆盖不足。

## 按影响排列的发现

### FD01 / P1：研究用期末成分回看历史（DATA01/03/06、A37）

位置：`scripts/run_factor_slice.py:48`、`run_factor_research.py:59`、`run_factor_walkforward.py:64`均调用`universe_on(end)`，随后对整个日期区间填因子/标签，没有逐日成分掩码。

实际2025-01-02至2026-09-24有421交易日、643个曾在册标的，脚本只选期末500个。按供应商区间解释，2025-01-02在册501个，其中133个被期末池漏掉；期末池另含132个当日非成分的候选。后者不表示132个都产生有效样本，但候选选择已使用未来成员信息。2015-01-05的历史500个里有413个不在期末池。供应商某日501个的原因需单独与指数调整资料核验，不能机械截断成500。

影响：产生历史成分选择/生存者偏差，改变横截面排名、统计行业、暴露、中性化、IC和筛选结论；退市数据“存在库里”并不代表实际被纳入研究。修复须沿日期读取历史成员并覆盖全部因子/标签/暴露路径，保留排除原因。

### FD02 / P1：通用因子入口对已复权close再乘factor（DATA03、A30/A37）

位置：`extensions/workbench/quant_workbench/factors.py:128`—`131`；`services/factors.py:91`调用该读取器。免费研究脚本直接读取close，此缺陷不能混称为它们也做了二次复权。

按清单锁定的[供应商归一化代码](https://github.com/chenditc/investment_data/blob/b8c129b4d9b838f050eac8b1135111b3b79fc894/qlib/normalize.py)及其[Qlib归一化实现](https://github.com/microsoft/qlib/blob/b87a2c294d364a33fb739359886acffe8ec907d1/scripts/data_collector/yahoo/collector.py)，close已经复权并按首个有效close归一化；factor用于恢复原价，不应再次乘入收益标签。

真实文件直接调用通用读取器：SH600000在2026-07-15→07-16，直接close收益为−0.4531%，通用入口变成+4.2466%；2025-07-15→07-16为−0.2942%→+2.7312%。这会把factor跳变误记成额外收益。**未断言现有UI/已存因子都使用此免费快照**：当前分析还有profile/版本接入限制；已证明的是该读取器一旦处理此格式，数值错误。

修复须按来源/物化版本声明价格口径，仅转换一次；不能不区分旧原价格式便全局删乘法。未知口径拒算；增加真实除权窗口跨入口一致性回归，旧结果保留并标受影响范围。

### FD03 / P1：物化重复证券区间、忽略有效期与字段起点（DATA05、A17/A38）

位置：`data_directory.py:151`—`173`。instruments每行是“证券+区间”，代码直接当证券列表并先截前N行，再对每行输出整段行情；没有去重，也没有按该证券在当日的成员身份过滤。字段共用首字段bin起点。

两份现存`panel-csi500-2026-09-01-*.csv`各360行，却都只有1只股票、18个唯一(date,symbol)，重复342行。摘要仍与原物化证据一致：**稳定重放了重复数据**，不是有效20标的面板。隔离夹具进一步证明会输出离开成分池的中间日期，且不同字段起点错开一天时bar检查仍通过、物化按同一偏移配对。

修复须按有效期展开唯一键，limit作用于明确排序的唯一标的；字段各自按header对齐日历。缺字段/长度差异/越界不能静默截到最短后称全量成功。原样例保留为错误历史证据，新物化器版本另产出。

### FD04 / P1：训练切片包含测试期才成熟的标签（CN03、VAL、A36/A37）

位置：`run_factor_walkforward.py:111`—`112`先计算全区间未来标签，`:154`以后直接用`ic_series[train]`与`spread_series[train]`选因子，未按标签结束时间purge。

隔离421日夹具第一折train索引[0,120)、test从120开始；h=5时末5个训练特征日标签依赖test价格，h=10时为末10个。仅将test首日价格100改成120，训练区间内h=5的第115行、h=10的第110行标签就改变。代码的“只用训练窗口选因子”声明不成立。

修复须在每折选择前按标签可用时间裁剪，IC、分位差和成本筛选共用同一合法样本；固定训练截止时间时，任意修改其后的价格不得改变该折训练统计或选择结果。已有SR06缺IC压缩时间轴问题也仍需修复，两个问题不能互相替代。

### FD05 / P1：使用的组件不受内容身份完整保护（既有SR05细化）

位置：`verify_free_snapshot.py:167`以后的组件登记、`data_directory.py::component_digest/load_snapshot/FreeSnapshotReader`及三个研究脚本的`--enrichment`路径。

bar登记的是压缩归档哈希，却没有把当前解包字节绑定到该归档；status摘要只哈希文件/行数/起止日期等统计，改换手率而保持计数不变就不会改变该摘要；universe仅登记all.txt，真正研究使用的csi500.txt未独立绑定；研究额外接收任意enrichment路径。隔离反例改变日历内容后，原snapshot摘要不变，读取与validate仍通过；draft也能物化。

修复继续遵守DATA04-A：绑定所有实际消费的bar、指定成分、状态/换手、日历及物化解释版本；内容变化产生新身份；组件无法验证或非published拒绝可复现分析。不能以采样数量或原archive通过替代消费字节校验。

### FD06 / P1：先发布后检查，质量失败仍退出0（DATA05、A16/A17）

位置：`scripts/register_free_snapshot.py:46`先publish，`:60`才bar检查，`:106`无条件return 0。最终打印ok也没包含manifest验证和两次物化摘要一致性的全部结果。

临时夹具包含负收盘价，bar gate为false，但进程退出0，registry中仍为published。修复须先在暂存版本完成必需门禁，失败保留失败证据但不产生健康published身份；退出码非0。全部必要检查决定最终结果，不能由打印字段代替发布状态机。

### FD07 / P2：缓存存在即跳过，游标中途失败仍缓存为成功（DATA05）

位置：`scripts/fetch_csi500_turnover.py:83`—`103`，`free_sources.py::load_turnover_csv`。

只要文件非空就跳过，没有验证请求起止区间与覆盖，也不在result.next循环结束后检查源错误。隔离反例：只有CSV表头也返回skipped；先返回1行再出现黑名单错误的模拟游标，脚本写入1行并返回ok:1；重复日期解析静默保留最后一行。更换--end沿用目录也不会更新已有文件。

本轮1791个真实缓存未见重复日期，**没有证据断言这些文件已被上述中途错误截断**；缺陷在于当前恢复机制无法证明确认完整。修复须记录请求范围、成功完成标记、返回覆盖及内容摘要，逐行校验并检查游标终态；仅兼容且已验证完整的缓存可跳过；部分结果隔离保留，不能升格为成功缓存，不覆盖现有珍贵缓存。

## 规范自身的纠正与边界

DATA_SOURCES已同步纠正：百分数turn的股本公式少写了“÷100”；“factor首日=1”实际是close首个有效值=1；一个原价示例误写乘号；单点0.025%误差不能宣称普适精度。旧“接近完成/发布不可追加/物化可复跑”均收窄到其真实证据范围。

停牌/一字板仍有规则缺口：`label_tradability`只检查两端，内部停牌仍可通过，与DATA_SOURCES既有“窗口内剔除”要求不一致；固定9.8%/4.8%阈值也不是按证券、日期确定的正式涨跌停规则。未查询交易所规则，未认定真实样本误分类数量；正式成交/成本结论必须继续标受限，收盘预测标签不能当可实现收益。

## 执行顺序与退出条件

本轮不改变原SR01—03执行安全优先级。数据专项先完成FD05/FD06，建立可信输入与发布；再修FD03/FD07确保面板和缓存正确；研究前必须同时修FD01/FD02/FD04及SR06，并冻结停牌/涨跌停的所需范围。每项按DATA_SOURCES §10验收，修复后重跑受影响研究，不覆盖原快照、旧物化或旧结果。任何单项通过均不关闭T05/T08/A37整体。
