## 1. 规范本身

### 应保留的设计

- 独立工作台包、外部 Qlib/RD-Agent 适配、CLI/HTTP 共用应用服务，适合继续接收上游改进。无需为当前单人本机系统引入微服务或通用插件市场。
- 不可变结果 revision、来源实例身份、数据内容版本与配置指纹分开，方向正确。
- 运行成功、产物存在、质量检查、策略有效性分开；原始记录、派生计算、意见和模拟性质分开，是必要的产品约束。

## 2. 已确认的实现缺陷

代码位置均相对于仓库根目录；行号对应上述基线。复现见第 4 节，不以推测代替实测。

### R01 — P1：RD-Agent 多轮结果被混合归属

- 位置：[export_rdagent_research.py](../../../scripts/export_rdagent_research.py)，81—105 行。
- `factors` 每轮清空，但 metrics、runner_report、effective、quality 只在本轮存在时更新。后一轮缺报告时，会沿用前轮报告；最后再无条件优先 runner_report。会话级标题、因子、指标、报告因此可能不属于同一实验。
- 隔离复现：第一轮报告末值 110；第二轮因子 factor1、IC 0.2、无报告。导出结果显示 factor1 / IC 0.2 / 权益 110，warnings 为空。
- 违反：ARC06、RW02/04、GOV-SOURCE/HISTORY。
- 修复验收：按会话内迭代/实验身份聚合，每项保留产物来源和关联；新轮缺产物显示缺失，旧轮结果独立可查。至少覆盖成功后失败、报告与反馈交错、多 workspace、解析部分失败。

### R02 — P1：平台结果先入库，随后才脱敏

- 位置：[export_rdagent_research.py](../../../scripts/export_rdagent_research.py)，138—157 行。
- quality / effective 的嵌套字符串未经统一清洗进入 package，149 行发布后，157 行只清洗快照。相同信息经 revision 的 evidence 接口仍可能原样暴露。
- 使用**虚构占位密钥**写入临时 effective.account.assumptions：快照中已脱敏，已发布 package 中仍存在。没有证明真实历史结果已泄露真实密钥，也没有输出或写入用户真实密钥。
- 违反：AGENT02、RW03、GOV-SOURCE。
- 修复验收：对所有要持久化/返回的字符串在首次发布前统一脱敏，快照和结果库使用同一已清洗证据；增加不同敏感字段、异常字符串、日志及 HTTP evidence 的检查。若排查既有结果，须保留审计与修订路径，不能直接覆盖不可变对象。

### R03 — P1：导入声明可以覆盖已知模拟性质

- 位置：[export_rdagent_research.py](../../../scripts/export_rdagent_research.py)，145—149、168—173 行；同类入口 [qlib_mlflow.py](../../../extensions/workbench/quant_workbench/adapters/qlib_mlflow.py)，最终 run.synthetic 赋值。
- 导出直接采用 CLI synthetic 布尔值，未校验有效配置中的 research.synthetic。传 --real 可将明确的 synthetic=true 产物发布为 synthetic=false。
- 隔离复现保留原 synthetic=true 配置，导出结果却是 false；这会消失模拟标记。Qlib 入口同样信任调用参数（代码检查，未追加运行真实导入）。
- 违反：ARC06/08、CN05、GOV-SOURCE/HISTORY。
- 修复验收：有源证据时以证据为准、冲突拒绝；无源证据的用户声明单独记录，不能伪装来源认证。覆盖真实/模拟冲突、未知来源与 fixture；CLI 标签不可覆盖更强证据。

### R04 — P1：常规导入仍可能自动迁移源 MLflow 数据库

- 位置：[qlib_mlflow.py](../../../extensions/workbench/quant_workbench/adapters/qlib_mlflow.py)，48 行；[test_qlib_integration.py](../../../extensions/workbench/tests/test_qlib_integration.py)，25—26 行。
- 审计脚本已用源库副本，但普通导入器及集成测试仍把源 tracking_uri 直接交给 MlflowClient。将来换用较新 MLflow，读取即可迁移历史库。
- 仅对只读源库备份出的临时副本验证：MLflow 3.16.1 调用 get_experiment_by_name 后，schema 从 7d34483879f0 变为 b7e2c1a4d9f3；原库 SHA256 不变。本次常规测试使用匹配的 3.12 环境。
- 违反：OPS02、GOV-STORAGE、STORE03。
- 修复验收：所有只读导入/测试统一使用隔离副本或真正禁止写入的后端；未知数据库拒绝自动变更。匹配/较新/较旧客户端分别验证源库内容与 schema 不变，升级另走迁移流程。

### R05 — P1：比较错误允许不同数据集及缺测序列排名

- 位置：[application.py](../../../extensions/workbench/quant_workbench/application.py)，95—117 行。
- 只比较 dataset.version 字符串，没比较数据集身份；只比较时间首尾，没检查缺测覆盖；相同 null 的口径字段可通过相等性检查。情景指纹相同不能补足这些证据。
- 隔离复现：数据集 A/v1 与 B/v1，同情景、同首末日期，第二条中间权益缺测，返回 comparable / ranking_allowed=true。夹具同时缺 currency，但核心错误不依赖币种字段：不同数据集与缺测仍被放行。
- 违反：COMPARE01、RW05、GOV-SOURCE。
- 修复验收：分维度测试身份、版本、有效覆盖及必要口径；缺失证据拒绝排名并说明原因；先明确定义 S04 的模式，再解除 CN 指纹对通用指标的硬编码。

### R06 — P1：UI 把第一页末点当作期末，前后页面数值可能矛盾

- 位置：[app.js](../../../extensions/workbench/quant_workbench/ui/app.js)，77—89、101—102、122—129 行。
- series() 不消费 next_offset，也不显示截断。回测期末值/费用/最大回撤、训练末点、比较变化在浏览器按首 2000 点计算，review 服务则按完整序列计算。
- 对真实 series() 函数模拟 total_points=2001、next_offset=2000：只发一次请求且返回首分页数据。静态核对确认展示用其末点，未检查分页提示。当前历史短序列不触发，不代表长期数据安全。
- 违反：ARC02/07、UI02、A15、RW05。
- 修复验收：摘要统一由应用服务按锁定 revision 全量计算；图表用有界分页/明确降采样和范围标识。2001 点以上、极值落在尾页时，CLI/API/UI 的期末值和回撤一致，不得改成无限下载。

### R07 — P2：查询失败被包装成“未记录”

- 位置：[app.js](../../../extensions/workbench/quant_workbench/ui/app.js)，77—78 行。
- catch 无条件返回 null；后续呈现没有权益或未知指标，用户无法区分服务故障、请求错误与源产物缺失。
- JavaScript VM 直接调用现有函数，HTTP 500 得到 null，无错误。
- 违反：ARC08、METRIC03、A12。
- 修复验收：结构化区分 404/未记录、empty、unsupported、5xx/网络失败，保留 request_id 与重试入口；失败不得被摘要吞掉。

### R08 — P2：缺测点从图中消失，并被直线跨过

- 位置：[app.js](../../../extensions/workbench/quant_workbench/ui/app.js)，61—68 行。

- 真实 chart() 输入 [1,null,3] 输出一条连续 polyline，缺口不显示。
- 违反：METRIC02/03、ARC08、UI01。
- 修复验收：按轴语义定位，缺测断线、显示原因/覆盖；时间与 step 间隔不等的夹具不会画成等距连续观测。交易日期可采用明确声明的交易日轴。

### R09 — P2：合法的空序列触发 UnboundLocalError

- 位置：[model.py](../../../extensions/workbench/quant_workbench/model.py)，107—111、140 行。
- axis 仅在逐点循环内赋值，第一条序列 points=[] 时循环不执行，140 行引用未赋值局部变量。empty/not_recorded/unsupported/error 本应合法。
- 单条 unsupported 空序列实测抛 UnboundLocalError。
- 违反：METRIC02/03、A03/A12。
- 修复验收：轴校验移到序列层；每种合法不可用状态、首条/中间空序列、空 scalar 都能验证；非法输入继续返回 ContractError。

### R10 — P2：服务端摘要把最后非空值当作报告期末值

- 位置：[research.py](../../../extensions/workbench/quant_workbench/research.py)，10—26 行。

- 违反：METRIC03/05、RW05、GOV-DERIVED。
- 修复验收：期末缺失应返回 null+原因；如另展示最后有效观测，必须单独字段、日期和覆盖。首末及中间缺测不能隐式改变总区间；回撤缺口明确限制。

### R11 — P2：带时区时间轴按字符串比较顺序

### R12 — P2：嵌套配置的未知参数仍被静默接受
