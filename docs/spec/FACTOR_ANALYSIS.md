## 1. 范围与原则

因子层回答的是「这个因子有没有用、有多有用、和别的因子有多像」，与「某个回测跑出什么组合结果」是两个不同层次的问题：

| 层次 | 分析单元 | 可回答 | 不可回答 |
| --- | --- | --- | --- |
| 回测层 | 运行（组合/账户） | 同一把尺子下的组合表现差异 | 某个因子是否独立有效 |
| 因子层 | 因子（`datetime × instrument` 面板） | 单因子预测力、显著性、效应量、两两重叠、对现有集合的增量 | 交易成本、容量与拥挤（缺少持仓/成交数据） |

- 单因子指标属于**工作台计算**，必须带公式、输入数据内容版本与样本区间；不得与引擎原生指标混标。
- 因子面板是**新的数据种类**，按 DATA 系列的数据目录规则入库：不可变、内容可校验、有来源与限度。
- 显著性不等于可用性；探针与探索性研究得出的因子一律标记为探索性，多重检验必须披露测试数量。

## 2. 比较分组（U18）

分析指标按训练/研究/回测业务语义分组（不按引擎名称推断），指标集合互有缺口，因此**不得对全量指标做统一排名**：

| 组 | 典型指标 | 排名规则 |
| --- | --- | --- |
| 训练 | 逐步 loss 曲线、逐迭代指标、模型超参 | 同一模型/同一数据版本的曲线可并排；不产生「最优运行」结论 |
| 研究 | 因子定义、生成代码、合并后研究与质量指标 | 并排查看与过程比较；不与其他组比大小 |
| 回测 | 权益、回撤、成本、换手、组合指标 | 同一把尺子（数据内容 + 执行口径 + 评估口径）下可排名 |
| 其他/未登记 | 方向或分组未登记的指标 | 只并排，并写明原因 |

规则：

- 当前只有回测组在结果合同的口径检查通过后可排名；训练、研究、其他组及跨组一律只并排。U18“组内才排名”是必要条件，不代表每组已支持排名；将来增加训练/研究排名须另定义评估协议并验收。
- 指标分组是服务端登记的（不是 UI 猜测）；新增指标必须同时登记分组与方向，未登记则为「其他/未登记」。
- 分组不改变来源标记与可用性表达：模拟、探针、未接入继续照常标注。

## 3. 因子实体与面板入库（U19）

### 3.1 因子实体

| 字段 | 语义 |
| --- | --- |
| `factor_id` | 平台不透明 ID，跨重启稳定 |
| `name` | 因子名（与来源一致，不重命名） |
| `definition` | 公式、变量说明、生成代码摘要与代码哈希（可为空，但必须显式标记未记录） |
| `source` | 来源实例与实验定位（例如 RD-Agent 会话/实验键，或人工导入） |
| `dataset` | 数据集 id 与内容版本；面板必须与某个已记录的数据内容版本绑定 |
| `calendar_id` | 交易日历身份 |
| `provenance` | 因子定义来源（引擎产物/人工）与文档限度 |

### 3.2 面板格式与边界

面板是 `datetime × instrument` 的数值矩阵，按因子分别入库（一个因子一个面板）：

- 规范 JSON：`{schema_version, factor_id, name, calendar_id, dates[], instruments[], values[]}`，`values` 为按 `(date, instrument)` 行主序的数组，缺测为 `null`。
- 当前JSON单对象/导入入口限制：`dates ≤ 2000`、`instruments ≤ 2000`、单元格 `≤ 400000`、单对象 `≤ 16MB`；该入口超限仍必须拒绝并说明，不能直接取消保护。它不是长期持久化数据集的容量合同（DATA06）。
- 内容校验：日期严格递增且唯一、instrument 唯一、值必须有限（NaN/Inf 拒绝）、`null` 表示缺测且不得填 0。
- 不可变：同一 `(factor, 数据内容版本, 内容哈希)` 重复导入复用既有面板；内容变化产生新面板，旧面板保留。

后续分块面板合同（DATA06 / A38）：逻辑面板由不可变清单及分块组成，记录格式版本、分区范围、摘要、行数、单位、来源和缺失规则；发布前验证重叠/缺块/覆盖，重复导入复用，旧对象不覆盖。分析按窗口和计算预算读取，浏览器只取有界摘要/分页。单次分析需声明因子/样本上限、超时与内存预算，超限可拒绝或明确要求缩小范围，不能静默截样后报告全样本结果。当前无分块导入/分析能力；至少以500标的×1000日期跨块夹具验收，不把该夹具规模当长期上限。

### 3.3 未来收益（标签）由平台计算

单因子 IC 需要未来收益。平台按声明公式从**已记录的数据快照**计算，不引入外部数据：

- 收益：`r_{t→t+h} = close_{t+h} / close_t - 1`，`close` 取自快照的复权/因子字段；`h` 为持有期交易日数。
- 只使用与因子面板同一数据集内容版本与日历的快照；快照缺失该字段时不得猜测，直接返回 `not_available`。
- 标签属于工作台计算，必须随结果返回公式、`h`、数据内容版本与样本区间。因子可用时刻、预测基准时刻与可交易时刻分别记录；收盘到未来收盘的预测标签不自动代表可实现交易收益。真实研究还需声明股票池有效期、缺失/停牌处理及预处理拟合范围；缺失时保留限制。

## 4. 分析口径（U19）

### 4.1 单因子

| 指标 | 公式/口径 | 说明 |
| --- | --- | --- |
| `coverage` | 有效单元格 / 全部单元格，另有逐日覆盖率 | 缺测不填 0 |
| `ic_mean` | 每个交易日横截面 Pearson 相关（因子 vs 未来收益）的均值 | 与样本区间绑定 |
| `rank_ic_mean` | 同上，改用秩相关（Spearman） | 对异常值更稳健 |
| `ic_std` / `icir` | IC 序列标准差；`icir = ic_mean / ic_std` | `ic_std=0` 时 `icir=null` |
| `t_stat` / `p_value` | `t = ic_mean / se_mean`；se_mean是均值的Newey-West标准误，不能再除sqrt(N)。滞后L=min(h−1,N−1)，p为双侧正态近似 | 估计量定义见下；v2使用nw_se_mean；旧版算法保留但不满足本定义 |
| `fdr_q` | Benjamini-Hochberg 校正后的 q 值 | 必须披露参与检验的因子数量 |
| `quantile_spread` | 按因子分 5 组的平均未来收益 Q5−Q1 | 当前仅输出单调性代理：组号与组均值的Pearson相关绝对值>0.8，且`(Q5−Q1>0)==(corr>0)`；此为既有布尔判定，不等于逐组严格单调或经济有效性 |
| `decay` | 同一因子在 `h ∈ {1,5,10,20}` 下的 `ic_mean` | 描述因子衰减 |
| `turnover` | 横截面秩的平均换手（相邻交易日的秩变动） | 高换手意味着更高交易成本风险 |

均值标准误定义（新分析版本2）：对完整等间隔IC序列x，N为观测数，`gamma_k = sum((x_t-mean(x))*(x_{t-k}-mean(x)), t=k..N-1)/N`；`omega = gamma_0 + 2*sum((1-k/(L+1))*gamma_k, k=1..L)`；`se_mean=sqrt(omega/N)`。本定义不使用额外小样本修正，omega≤0或标准误非有限时返回不可用；至少N≥max(10,L+2)，有缺失交易日时本版显著性不可用而IC描述统计可保留，不将删缺口后的相邻观测当相邻交易日。算法约定参照 [statsmodels HAC文档](https://www.statsmodels.org/dev/generated/statsmodels.stats.sandwich_covariance.cov_hac.html) 的Bartlett权重；不依赖其默认lag或小样本修正。

独立样例：h=1，IC为十项交替−0.1/+0.1，均值0、omega=0.01、se_mean=sqrt(0.001)、t=0；全部为0.1时标准误为0，显著性不可用。已核对：旧实现滞后协方差使用N−k分母且将方差下限设为1e−18；v2使用N且不设地板，两个版本可能不同，历史数值不覆盖。

### 4.2 重叠性家族

| 指标 | 口径 | 当前可用性 |
| --- | --- | --- |
| `value_correlation` | 逐日横截面秩相关的均值（两两） | 面板齐备时可用 |
| `collinearity` | 由相关矩阵计算 VIF | 相关矩阵可逆时可用；否则返回原因 |
| `absolute_correlation_similarity`（新定义） | `abs(corr)`（逐对），越大表示越相似；只表示相关相似度，不证明非线性冗余 | v2已实现；面板与有效相关值齐备才可算 |
| `correlation_distance`（新定义） | `1 - abs(corr)`（逐对），越大表示越不相似 | v2已实现命名纠正；旧字段 `redundancy` 实际计算此值，不能解读为越大越冗余 |
| `ic_series_correlation` | 两因子 IC 序列的相关系数 | 需要双方 IC 序列，平台可算 |
| `orthogonal_ic` | 新因子对既有因子集合横截面回归取残差后的 IC | 已有探索性输出；既有增量混用Pearson/Spearman，A30未通过，须统一方法后复验 |
| `incremental_ic` | 等权合成 `既有集合 + 新因子` 前后的合成 IC 差 | 已有探索性输出；留一组合样本可能不同，A30未通过，须在共同有效样本上复验 |
| `holding_overlap` | 组合持仓重叠 | **未接入**：缺少持仓/成交明细 |
| `crowding` | 因子拥挤度 | **未接入**：需要市场层面使用数据 |

未接入项必须在同一结果中显式返回 `not_available` 与缺失输入名称，不得省略或以 0 代替。

两个新字段中的corr均指同一对因子的value_correlation（先求逐日相关，再对有效日期平均）；先取绝对值再平均是不同指标，禁止混用。例如逐日相关+1、−1时corr=0，本定义相似度为0；必须同时保留有符号相关与有效日期数，不能宣称已排除非线性冗余。分析版本选择与DTO兼容规则统一见 [RESULT_CONTRACT](RESULT_CONTRACT.md)。

兼容：旧 `redundancy` 数值与历史结果保持不变，保留其原公式并标注命名局限；后续以新字段和definition_id发布，不在同名旧字段下直接把 `1-abs(corr)` 改成 `abs(corr)`。DTO、UI方向与契约样例需一并更新。

### 4.2A 研究脚本共享统计与缺测边界（SR06，生效补充）

研究脚本与API/CLI遵守同一§4.1及T01-F日期轴/NW/FDR合同；脚本只编排参数、输入和输出，不复制估计公式。共享服务接收已锁定的数据/日历身份、预先确定的研究窗口、horizon及带日期的IC，不能只接收过滤后的浮点列表。

- 先按快照交易日构建完整窗口；仅窗口末尾因未来h个交易日标签尚未成熟的区间可按T01-F规则从检验窗口排除，须记录这些日期与原因。不能依据IC是否为空来反向选择研究起止日期。
- 保留窗口内的缺测、样本不足或不可交易导致的缺IC日期；任一内部缺IC使该因子的显著性不可用，t/p为null、说明原因，不参加该次BH-FDR。描述统计可独立返回并披露有效天数，不能把描述统计可用当作显著性可用。
- FDR同时披露请求假设、成功检验假设与排除原因；无有效检验时输出不可用，不写“0个显著”冒充一次有效检验。依赖FDR的选择必须传播不可用状态，不能把null视为通过。
- 修复必须同时覆盖factor_pipeline、run_factor_research和run_factor_walkforward；只改NW helper而调用方仍先删空值不算修复。完整日历、内部缺日、非有限IC、尾部未成熟、零方差分别验收，完整输入与主分析统计同值。
- 重新生成受影响的研究/FDR/选择证据，记录代码和定义版本、输入快照/组件摘要、窗口与排除项；追加纠正记录，不覆盖原证据。若真实输入不可用，只能关闭算法子项，真实试点复验仍开放。SR06不同时认证purge/embargo、历史股票池、PIT或完整T07/A37。


### 4.3 输出与标记

- 每个分析结果带 `basis`（公式、持有期、样本区间、因子集合）及 `limitations`。当前DTO的数据内容版本位于 `basis.dataset.version`，选中因子数位于 `basis.factor_count`；v2实际FDR检验数另为 `basis.parameters.tested_factor_count`，请求因子数为 `basis.parameters.requested_factor_count`。`data_version`为语义称呼，不是已存在的顶层字段；不得把选中数量当成实际成功检验数量。
- 单一分析请求的因子数量与面板规模有上限；超出返回拒绝原因与建议。
- 探针来源的因子在结果中标记探索性；不得以「通过了显著性」对外声称策略有效。

- 相关输出同时保留有符号矩阵与有效日期数；新相似度/距离按逐对 `pairs` 返回 `left/right/correlation/valid_days/value/definition`。v2不返回旧redundancy字段。每个计算项/统计族提供定义卡，input_refs锁定因子panel_id、content_hash、数据摘要和日历，缺来源性质标unknown，不猜测真实/模拟。同名因子暂拒绝一起分析，防止以名称为键的旧诊断覆盖结果；未记录日历身份拒绝v2请求。
- BH-FDR只使用主horizon中显著性可用的Rank IC，分别披露请求因子数和实际检验数；失败项不填0，不声称覆盖未导入或未验证的试验全集。NW不加方差地板；精确常数序列直接判零方差，避免均值浮点舍入造出虚假显著性。
- 此切片验证NW/命名/日期对齐，不认证其余估计量或真实研究有效性。发现的既有换手跨缺口、正交增量混用Pearson/Spearman、留一组合样本不一致仍是待修缺陷，披露不构成放宽§4口径或通过A30；这些字段保留明确的旧算法说明，后续须修正并复验。价格加载暂沿用既有close与可选factor规则，并披露其为当前物化解释；完整价格复权语义、PIT和供应商历史修订验证归数据目录/真实研究验收，不宣称已证明“未使用未来修订数据”。

## 人参与研究的正交评价补充（HR07，生效目标，待实现）

[HUMAN_RESEARCH](HUMAN_RESEARCH.md)要求自动评价公式，但不能把现有混合相关方法的正交增量当作纠正后结果。冻结新定义`factor_orthogonal_v1`，由未来analysis_version=3响应承载；现有v1/v2结果不重写，新研究入口在此定义未实现时返回unavailable/estimator_not_validated，不能标已支持正交。此补充不改变已有NW/缺IC/FDR算法。

每个日期t、每个h、目标因子F和冻结参考集B，在历史成员/当前因子状态与完整窗口标签掩码后，取F、所有B及标签Y均有限的共同截面S_t；在该截面内重算所有秩。秩用平均并列秩，分别中心化并按样本标准差(ddof=1)标准化；常数列不可用。n≥max(5,k+3)，k为参考列数；不足返回insufficient_cross_section。无参考集返回reference_set_missing，不能用0作正交结果。

构造Z=[1,rank(B1),…,rank(Bk)]，用确定性最小二乘分别残差化rank(F)与rank(Y)，返回二者**Pearson相关**作为partial_rank_ic。该名称不冒充传统原始IC。使用float64/SVD，秩判定阈值=max(n,k+1)×机器epsilon×最大奇异值，秩亏返回reference_rank_deficient，不暗中删列；残差范数≤1e-12×max(原向量范数,1)返回zero_residual_variance。报告输入参考版本、样本、阈值、系数与状态。残差化Y只为事后相关诊断，禁止把Y或其系数传给可交易因子/预测管线；真正生成正交因子只允许F对当时可用B的变换，另建有时间语义的因子定义。

等权增量诊断使用同一S_t和同一标准化秩输入：full=Pearson(mean(rank(F),rank(B)),rank(Y))；without=Pearson(mean(rank(B)),rank(Y))；delta=full-without。预期方向符号若使用必须事前冻结，对full/without一致应用；不按结果翻符号。full/without各自退化则delta不可用，不在两个不同样本集上相减。跨日期均值/NW完整轴规则沿用§4.1，明确描述性共同样本覆盖；不能用正交相关证明经济独立、因果关系或成本后收益。

独立验收oracle：n=6，B=[1,2,3,4,5,6]，F=[2,4,1,6,3,5]，Y=F时partial_rank_ic=1，Y=-F时为-1（1e-10容差）；F=B时zero_residual_variance；B重复两列时reference_rank_deficient；无参考集不可用；给其中一列插null后按共同S_t重算，与独立手算/最小二乘实现一致。新增未来价格不得改变此前生成的因子值，但可改变对应尚未成熟标签；验证分割/拟合范围继续服从VALIDATION。
